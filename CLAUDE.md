# Project notes for the agent

- This is a Vite + React static site deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`. It serves at `https://<domain>/<repo-name>/`.
- `package.json` "name" must equal the GitHub repo name. `vite.config.js` derives the `base` path from it.
- `site.config.js` holds the domain, title, description, and OG copy. `scripts/prerender.mjs` reads it at build time and writes the meta tags, JSON-LD, sitemap, and the index-site embed script tags into `dist/index.html`, plus one prerendered page per current FBS team at `dist/team/<id>/index.html` with its own OG image.
- `npm run build` is `vite build` plus the prerender. The deployed HTML contains the rendered page, so `src/main.jsx` uses `hydrateRoot`, and nothing may read `window` during render. Apply URL state in a `useEffect` after mount. The only path-derived state is the open team (`/team/<id>/`), passed in as the `initial` prop.
- Shareable state goes in the URL with one `replaceState` per change (`writeUrl` in `src/urlState.js`): params `c` (chips), `dir=L`, `scope=active` (default is all-time), `week=1`, `run`. The analytics embed counts each `replaceState` as a pageview.
- Analytics: `window.dhAnalytics?.track(name, props)`, optional-chained because the embed is third-party and blockable. Events: definition, preset, team open, show more, share, save/unsave/apply saved streak, lead apply, leads scope, leads dir, week filter.
- Hover interactions use `onPointer*` events, not `onMouse*`, so they work on touch.
- Favicon and OG images are generated by `npm run gen:favicon` and `npm run gen:og` on a developer machine and committed. CI does not regenerate them. `gen:og` writes `public/og.png`, `public/card.png` and 136 team cards under `public/og/team/`, drawing the real default board from the payload, so re-run it after a redesign, after any grid rule change (it mirrors the column layout, including the reserved top slot on a live run), and whenever a fresher board is worth committing. Text is drawn as opentype.js glyph outlines: sharp's librsvg ignores `FONTCONFIG_FILE`, and opentype.js 2.x emits NaN path data, so it is pinned to 1.3.4.
- Social crawlers fetch the exact URL's HTML without JS and GitHub Pages ignores query strings, so only the root and the team pages get their own preview. Per-definition previews need a proxy that rewrites `<head>` (Cloudflare worker plan in the spec); not built.
- Dev server: `npm run dev`. If port 5173 is busy, `npm run dev -- --port 5174`.
- Worktrees: `data/raw/` and `data/build/` live only in the main checkout. Symlink both into the worktree to run the pipeline, and never `git add -A` there, because the symlinks are not covered by the `.gitignore` directory patterns.
- Data rulings live in `data/ref/` and are applied at build time with fail-loud checks: `repole-errata.json` (parse-repole fails on an entry that matches no row), `coach-overrides.json` (build-payload must report 0 unresolved coach seasons), `alt-home.json`. After changing the errata, run `scripts/data/export-errata.mjs` against a checkout of `DrewHoo/repole-errata` and push it; that repo is the public CC0 copy.
- The `dataviz-pages-site` skill covers everything else: build-time data, researched datasets, mobile, dates, SEO, registering the project card on the index site.
